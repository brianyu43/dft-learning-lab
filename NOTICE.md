# Source and third-party materials

This public repository contains project source, experiment plans, structures,
curated factual tables, calculation summaries, and selected raw evidence from
completed or stopped local calculations. Publication does not mean that the
scientific project is complete.

No project-wide open-source license has been selected. Making the repository
public does not grant an additional blanket license. Existing third-party
licenses and attribution obligations remain applicable to their own materials.

The following local materials are not distributed here:

- ORCA installers, executables and bundled MPI libraries. Obtain ORCA from
  [FACCTs](https://www.faccts.de/orca/) under its applicable terms.
- Quantum ESPRESSO, xTB, Python environments, package caches and shared libraries.
  Version and build records are supplied; use the upstream projects to install them.
- Downloaded papers, supplementary PDFs, full-text extracts and rendered pages.
  Source DOIs, URLs, retrieval records and hashes remain in the research reports.
- Downloaded DeepCocrystal datasets, model archives, model code/configuration
  copies, and pseudopotential files. Follow the cited upstream sources and terms.
- The original private conversation and machine-specific ORCA environment script.

The included input geometries, numerical outputs, failure records and source
hashes must not be interpreted as experimental crystal structures, global-minimum
proofs, or validated predictions of cocrystal formation. See the experiment
protocols for the exact calculation scope.
