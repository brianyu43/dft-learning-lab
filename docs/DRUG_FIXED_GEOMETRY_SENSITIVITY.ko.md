## 비교 방법

먼저 각 조건의 에너지로 완결된 점수를 계산한다. `B = E(AB) − E(A) − E(B)`와 `X = E(AB) − E(AA)/2 − E(BB)/2`의 성분에 서로 다른 방법이나 환경의 총에너지를 섞지 않는다. 그다음 두 조건의 B 또는 X 차이를 비교한다.

종류별 진공 r2SCAN-3c 최저 자세를 S₀, 새 조건의 단일점 에너지로 고른 자세를 S₁이라 쓰면 점수 Q의 변화는 다음과 같이 나뉜다.

```
Q_new(S₁) − Q_base(S₀)
  = [Q_new(S₀) − Q_base(S₀)] + [Q_new(S₁) − Q_new(S₀)]
       같은 자세에서 조건을 바꾼 효과       새 조건에서 자세를 재선택한 효과
```

S는 이합체 하나만이 아니라 점수를 구성하는 단량체·자기 이합체·교차 이합체의 선택 묶음이다. 실제 구현에서는 기본 자세만 사용한 범위와 선택된 모든 자세를 사용한 범위를 유지하고, 각각 S₀ 고정·S₁ 재선택 결과를 모두 기록한다. 네 문헌 사례의 공통 분자 대조에서 동률 폭 0/0.5/1/2 kcal/mol마다 기존 판정과 새 판정의 변화를 보여준다. 네 대조를 독립 실험 4개로 세지 않는다.

## 입력 대응과 의미

`compare()`는 두 패널의 출발점 ID 집합, 종류, 기본/대안 역할과 좌표 SHA-256이 같아야 진행한다. 각 패널 내부에서는 방법·환경·수치 설정 ID·에너지 종류가 동일해야 한다. 현재 허용된 비교는 원래 계획의 다음 두 가지다.

- 진공 r2SCAN-3c 전자 에너지 → 같은 좌표의 진공 wB97X-3c 전자 에너지.
- 진공 r2SCAN-3c 전자 에너지 → 같은 좌표의 r2SCAN-3c SMD 에탄올 총에너지. 후자는 CDS를 이미 포함한 값이며 여기서 보정을 다시 더하지 않는다.

해시 문자열의 일치는 실제 파일 검증을 대신하지 않는다. 생산 호출자는 양쪽 패널의 원시 방법·기저·분산·용매·에너지 분해·기울기·좌표·출처와 모든 수치 검증을 먼저 마쳐야 한다. 다른 전하·스핀·화학적 상태를 같은 출발점으로 잘못 매핑하지 않았는지도 원시 단계의 책임이다. 공통 17개 시작점 전체를 요구하는 생산 단계의 검증도 별도로 유지한다.

양쪽에서 같은 대조군이 빠진 경우 일부 점수는 계산할 수 있어도 `all_scores_available`은 false이고, 해당 X와 변화량은 `null` 및 누락된 종류명으로 남는다. 한쪽에서만 출발점이 누락된 경우에는 비교를 거절한다. 실패를 미형성 예측으로 바꾸지 않는다.

## 검증 범위와 남은 연결

8개 검사는 해석적으로 답을 아는 인공 에너지로 B/X 변화, 방법별 조성 기준 에너지 이동의 상쇄, 자세 교체의 분해, SMD 에너지 양의 구분, 순위 역전과 모든 동률 폭, 누락 대조군, 잘못된 좌표/종류/역할/출처 대응과 비유한 에너지의 거부를 확인했다. 인공 해시는 파일을 인증하는 값이 아니다.

결과에는 항상 `raw_provenance_verified=false`, `numerical_precision_verified=false`, `target_method_or_solvent_minima_verified=false`를 표시한다. 이 함수의 검사 통과는 실제 DFT, 최소점, 수치 정밀도 또는 방법·용매 민감도 단계의 완료가 아니다. 실제 두 패널의 원시 출력이 확보되면 생산 검증기에서 입력 행을 구성하고 이 함수를 호출해야 한다. SMD 용매 최적화·진동과 대안 자세 보강은 이후에도 남는다.
