# 정밀도 진단 후 판정 기록

2026-09-29. 이 문서는 후속 계산 설계 검토이며, 이전 실패 판정을 통과로 바꾸는 승인 기록이 아니다. 약물 기본 패널의 공통 최적화 설정은 아직 확정하지 않았다.

## 실제 관측

동일한 두 좌표(DIF 단량체 및 검증된 DIF–DIF p05)에서 VeryTightSCF를 고정하고 DefGrid2, DefGrid3, DefGrid3+AngularGrid 7+IntAcc 6.0을 각각 적용했다. 여섯 계산 모두 출력·좌표·에너지·기울기 검증을 통과했다. 원시 자료는 `reports/completion/precision-diagnostic.json`과 여기에 연결된 개별 실행이다.

- DefGrid2→DefGrid3: 이합체 총에너지 변화 −0.649198 kcal/mol, 자기 결합 에너지 변화 −0.036856 kcal/mol.
- DefGrid3→dense: 이합체 총에너지 변화 +0.563453 kcal/mol, 자기 결합 에너지 변화 +0.004744 kcal/mol.
- DefGrid3→dense: 동일 이합체 좌표의 최대 기울기 성분 차이 1.1974369e-4 Eh/bohr. 이전 기하 민감도 기준 1e-4를 아직 충족하지 못했다.

이는 이 사례에서 총에너지 오차가 결합에너지 차이를 계산할 때 상당 부분 상쇄된다는 증거다. 다른 조합의 B/X, 구조의 격자 의존성, 자유에너지 또는 공결정 형성의 검증을 대신하지 않는다. dense는 이번 비교에서 더 조밀하게 정한 참조이며 정확한 무한 격자 한계로 간주하지 않는다.

## 다음 약물 계산의 결정 순서

1. 대표 단량체/이합체를 더 조밀한 공통 격자에서 최적화·진동 검증하여, 고정 좌표의 기울기 차이가 구조와 낮은 진동수에 미치는 영향을 확인한다. 기존 결과와 새 결과는 별도 경로로 보존한다.
2. 그 좌표에서 한 단계 더 엄격한 적분 설정의 에너지·기울기와 비교한다. 실제 입력과 ORCA 출력의 적용 설정을 확인한다. 기울기 기준을 사후에 완화하지 않는다.
3. 비용·최소점·기울기 확인 후 전체 패널의 공통 설정을 버전으로 고정한다. 설정이 달랐던 이전 최소점을 새 설정의 결과로 간주하지 않는다.
4. 모든 비교 성분에서 B/X의 격자 민감도를 계산한다. 목표 0.1 kcal/mol을 유지하며, 에너지 차이의 수치 안정성과 구조의 안정성은 서로 다른 판정으로 기록한다.

대표 계산의 추가 수치 정밀도 보정은 새 결합 자세 탐색으로 세지 않는다. 기존 17개 선택 시작점과 독립 평가의 선정 규칙은 유지한다. 반도체 기준 계산은 이 약물 격자 문제와 물리적으로 독립이므로 같은 시점에 준비할 수 있지만, 실제 연구 엔진은 한 번에 하나만 실행한다.

격자 설정의 의미는 [ORCA 6.1 공식 적분 격자 문서](https://www.faccts.de/docs/orca/6.1/manual/contents/essentialelements/numericalintegration.html)를 확인했다. 계산 결과의 판정은 문서의 일반 정확도 설명 대신 이 프로젝트의 실측 차이를 따른다.
