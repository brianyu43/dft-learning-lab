# 공통 정밀도 약물 패널의 시작점 연결

2026-09-29. 원래 선정된 시작점의 이력을 원시 파일에서 다시 확인했다. 입력을 새로 선정하거나 형성 라벨에 맞춰 바꾸지 않았다. 이 기록은 공통 정밀도에서 실제 계산을 완료했다는 뜻이 아니다.

## 고정된 범위

기본 단량체 5종과 이합체 9종에 기본 시작점이 하나씩 있다. 추가 시작점은 DIF–CAF 두 개와 DIF–ADE의 직접 양성자 이동 시작점 하나다. 합계는 **14종, 시작점 17개 = 기본 14개 + 추가 3개**다. 어떤 종류도 원래 상한인 3개를 넘지 않는다.

현재 9개 시작점에는 과거 설정에서 원시 Hessian·좌표·로그로 다시 확인한 최소점이 있다. 나머지 8개는 최초 DFT 계산이 미실행이다. 과거 시도는 중단·실패를 포함해 11건이며, 주파수 계산 재개나 정밀도 재최적화를 새 독립 시작점으로 세지 않는다.

|---|---|---|

## 보존한 이력

DIF–CAF p36은 원래 직렬 최적화 87단계가 완료된 뒤 진동 계산 도중 중단되었고, 같은 저장 좌표에서 12프로세스 Freq를 별도로 실행했다. 원래 실행을 정상 종료로 바꾸지 않고, 최적화 체크포인트·원시 로그·재개 Hessian이 같은 좌표를 가리키는지 확인했다.

DIF–DIF p05의 원래 −2.22950052 cm⁻¹과 재최적화 후 +9.18442963 cm⁻¹을 각각 남겼다. 재최적화 최소점은 그 설정에서의 국소 최소점이며, 이전 공통 격자 검사 실패도 유지한다. 새로운 대표 dense/strict 검증이 끝나기 전까지 과거 에너지는 새 공통 패널 비교에 승인하지 않는다.

ADE p36의 직접 이온 시작점은 원래 H18 이동을 유지한다. 이 좌표를 중성으로 돌아온 xTB 결과로 대체하지 않았다. 실제 DFT 이후의 수소 소유권과 전체 조성·전하는 다시 확인해야 한다.

## 실행 준비 도구와 아직 실행하지 않은 부분

`scripts/prepare_completion_drug_lineage.py`가 [고정 목록](../experiments/completion/drug-start-lineage-r1.json)을 생성했다. 251개 근거 파일의 해시와 17개 시작점의 원자 대응·기하 상태를 확인했다. 과거 최소점에는 전체 내부 진동의 양수 여부와 Hessian 좌표를 다시 검사했다. 공개되지 않은 결정 좌표나 전역 최소점에 대한 증명은 아니다.

`scripts/prepare_completion_uniform_drug.py`는 다음 순서로 작동하도록 작성했다.

1. 고정된 시작점과 대표 계산 입력·근거의 해시를 확인한다.
2. 기존 대표 정밀도 평가기를 통해 dense 최소점과 strict 단일점의 원시 Hessian·좌표·기울기·결합 에너지 차이를 재검증한다.
3. 대표 판정이 통과했을 때만 원래 17개 시작점을 공통 r2SCAN-3c/진공/dense 조건으로 연결한다. 대표 2건은 재사용하고 나머지 **15건의 Opt/Freq 입력**을 만든다. 이 중 기존 최소점의 공통 설정 재최적화는 7건, 기존 시작점의 최초 DFT는 8건이다.
4. 전체 입력·코드·근거 해시를 묶어 `uniform-vacuum-r4.json`을 만든다. 이 도구 자체는 엔진을 실행하지 않는다.

현재 이 도구는 문법 검사와 **대표 검증이 없는 상태에서 어떤 본 패널 입력도 생성하지 않는 사전조건 검사**를 통과했다. 대표 계산이 아직 미완료이므로 15건의 본 입력 생성 경로는 실제로 실행하지 않았다. 완성된 본 패널 계획 파일도 아직 없다.

대표 검증 이후 사용할 명령:

```sh
.venv/bin/python scripts/prepare_completion_uniform_drug.py
.venv/bin/python scripts/completion_batch.py --plan experiments/completion/uniform-vacuum-r4.json --execute
```

동시 연구 엔진 한 개, 12 MPI/OMP 1, 작업당 4시간, 프로세스 트리 RSS 40 GiB와 기존 약물 80시간 예산을 유지한다. 전체 최소점 이후에는 각 최종 좌표의 엄격한 격자 EnGrad와 실제 B/X 차이의 수치 민감도를 검증해야 한다. 대표 두 구조의 통과만으로 나머지 구조를 승인하지 않는다. wB97X-3c 및 에탄올 SP/Opt/Freq는 별도의 후속 묶음으로 남아 있다.
