# 반도체·약물 DFT 프로젝트의 학술 기여 가능성 조사

조사 기준일: 2026-09-09. 상태: 문헌 조사와 연구 설계 제안. 아래 파일럿 계산과 예측 모델 평가는 아직 실행하지 않았다. 기존 `PLAN.ko.md`는 학습 계획으로 보존한다.

**판단: 학습 과정은 유지하되, 연구 목표는 바꾸는 편이 좋다.** MoS₂–MoSe₂의 조성·변형별 밴드갭 표와 아세트아미노펜–공형성제 이합체 순위만으로는 독립적인 학술 기여가 약하다. 작은 계산이 최신 연구의 잘못된 판단을 발견하거나, 불확실한 판단에 추가 근거를 주도록 질문을 좁히자. 우선 약물의 실험 사례 검증을 시작하기가 더 수월하고, 반도체는 층간 에너지의 정밀도와 모델 적용 범위를 확인하는 파일럿이 선행돼야 한다. 이는 문헌에 근거한 제안이며 신규성이나 논문 게재 가능성을 확정한 판단은 아니다.

**현재 결과가 무엇인지**

프로젝트의 `reports/INSTALLATION.ko.md`를 확인했다. 지금 확보한 실제 계산은 물과 실리콘의 설치 검증용 단일점 계산이다. 아세트아미노펜의 최소점·공결정 순위, MoSSe의 수렴한 밴드구조·합금 안정성은 아직 없다. 따라서 기존 연구 결과를 학계에 제출하는 단계가 아니라, 앞으로 만들 결과의 용도를 정하는 단계다. 설치한 QE·ORCA·xTB·RDKit와 실행 기록 체계는 아래 방향에도 사용할 수 있다.

| 분야 | 기존 학습 목표 | 바꿀 연구 질문 | 결과를 사용할 연구자 |
|---|---|---|---|
| 반도체 | 단층 합금 조성·변형에 따른 밴드갭 | S/Se가 섞인 두 층에서, 층의 상대 위치에 따른 작은 에너지 차이를 계산 모델이 신뢰성 있게 구분하는가? | 2D 계면·모아레 구조 및 원자간 포텐셜 연구자 |
| 약물 | 공형성제 5종의 이합체 결합 에너지 | 실제 성공·실패 사례에서 자기끼리의 결합, 배좌, 용매를 고려한 DFT가 기존 예측에 추가 정보를 주는가? | 공결정 스크리닝·결정공학·제제 및 분자 예측 모델 연구자 |

**반도체: 알려진 합금에서, 최근의 계면 문제로 연결하기**

기존 조성·원자 배열 연구와의 중복은 구체적이다. 2018년 논문은 이미 Se 분율 0.25인 MoS₂(1−x)Se₂x에서 Se 배치와 전자 구조를 다뤘다. 2024년에는 더 넓은 Mo–W–S–Se 합금의 진동·라만 계산용 MACE 포텐셜이 발표됐다. 따라서 원래 33조건 표를 계산하거나 합금에 MLIP를 적용했다는 사실만으로 새 기여를 주장하기 어렵다. [2018 원논문](https://doi.org/10.1063/1.5011326), [2024 원논문](https://www.nature.com/articles/s41524-024-01357-9)

최근의 병목은 층 내부의 강한 결합과 층 사이의 약한 상호작용을 동시에 정확하게 계산하는 것이다. 2026-07-31 Nature Communications 논문은 전체 에너지·힘의 오차가 작아도 층의 쌓임 순서를 잘못 선호해 큰 모아레 구조를 틀릴 수 있음을 보여주고, 층 내부/층간 모델 분리와 구조 검증을 제안했다. 이 문제 자체는 이미 제기·해결 시도된 것이므로 우리의 발견으로 취급하지 않는다. [원논문](https://www.nature.com/articles/s41467-026-74482-2)

우리 소재와 연결되는 실험도 있다. 2025년 ACS Nano 연구에서는 MoSe₂/MoS₂ 계면의 S/Se 교환과 합금화가 격자 불일치를 줄이고 도메인 재구성을 가능하게 했다. 이 논문을 근거로, 합금화된 계면의 국소 에너지 지형을 후속 계산 대상으로 검토할 수 있다. 작은 셀에서 얻은 결과가 실제 열처리·확산·모아레 전체를 재현한다는 뜻은 아니다. [원논문·초록](https://pubmed.ncbi.nlm.nih.gov/41289598/)

제안 가설은 “전체 조성이 같아도 계면을 향하는 S/Se 배치가 층간 상대 위치의 에너지 순위에 영향을 주며, 일부 사용 가능한 모델은 그 차이를 수치 오차 이상으로 놓칠 수 있다”이다. 두 효과 모두 미확인이다. 조사한 주요 논문에서는 이 조건 조합에 대한 독립 검증을 확인하지 못했지만, 검색에서 찾지 못했다는 사실은 신규성 증명이 아니다.

파일럿은 다음 순서로 제한한다.

1. 공개된 순수 TMD 이중층의 기준 구조·에너지 차이를 재현한다. 원논문과 동일한 함수·분산 처리·의사퍼텐셜·층간 거리 정의를 우선 대조한다. 2026 논문의 공개 전신은 QE와 vdW-DF-C09를 사용한다. 최종판·저장소 입력과의 일치 여부를 실행 전에 확인한다. [방법 원문](https://arxiv.org/html/2503.15432v1)
2. MoS₂/MoSe₂ 이중층의 공통 면내 격자에서 상대 미끄러짐 3점 × 층간 거리 3점, 9개 고정 구조를 먼저 계산한다. 수렴 시험과 분리된 두 층의 기준 계산은 별도이므로 “9번 실행이면 끝”이라는 예산은 아니다.
3. 2×2 이중층, 총 24원자 안에서 전체 조성은 같고 계면 원소 배치가 다른 소수 구조로 확장한다. 각 구조의 실제 S/Se 원자 수와 대칭 중복을 확인한다. 18~36개 구조 상한은 첫 작업의 시간·정밀도를 보고 정한다.
4. 해당 원소와 물리 조건을 지원하는 공개 모델 1~2개와 비교한다. 순수 물질 전용 모델을 합금에 넣은 실패를 곧바로 모델 결함으로 부르지 않는다. 학습 데이터 포함 여부와 적용 범위 밖 사용 여부를 표시한다.

핵심 산출물은 구조별 층간 상호작용 에너지와 상대 위치의 순위, 힘, 수치 민감도다. 층간 에너지는 같은 셀·좌표 조건에서 `E(두 층) − E(위층만) − E(아래층만)`으로 구하고 면적당 단위도 제공한다. 서로 다른 면내 격자의 결과를 섞으면 탄성 변형 비용과 계면 효과가 혼동되므로 공통 격자 비교와 각자의 평형 격자 비교를 분리한다. 밴드갭은 구조 차이의 후속 영향을 보는 선택 항목이다. MLIP가 직접 밴드갭을 예측한다고 표현하지 않는다.

정확도는 기존 단층 계획의 1 meV/atom 목표를 자동 적용하지 않는다. 비교하려는 층간 에너지 차이보다 수치 불확실성이 충분히 작아야 한다. 파일럿에서 산출한 불확실성의 3배보다 작은 차이는 순위를 보류하는 운영 기준을 제안한다. 이는 통계적 유의성 검정이 아니다. 함수·분산 방식만 바꿔 순위가 달라지면 DFT 기준 자체가 불확실한 사례로 보고한다. 다른 함수로 학습된 MLIP와의 차이를 순수 모델 오차로 분해할 수 없으면 직접 정확도 순위를 내지 않는다.

이어갈 근거는 재현 가능한 에너지 순위 오류 또는 계면 배치 의존성이 나타나고, 기존 공개 벤치마크의 범위와 구별되며, 관련 모델을 개선·검증할 자료가 되는 경우다. 그런 신호가 없거나 기준 에너지 차이를 Mac에서 안정적으로 분해하지 못하면 이 단계는 재현 실습으로 마친다. 대형 비틀림 셀, 결함 확산 장벽, GW/BSE 광학 계산을 동시에 추가하지 않는다.

경쟁 연구는 반드시 포함해야 한다. 2025년에는 분산을 고려한 다층 TMD 모델, 2026-04에는 합금 상안정성을 포함한 자동 포텐셜 훈련, 2026-06에는 비틀린 2D 재료의 MACE 미세조정 프리프린트가 나왔다. “새 모델 훈련”이나 “2D에서 범용 모델 검사”처럼 넓은 제목은 이미 상당 부분 중복된다. [다층 TMD](https://www.nature.com/articles/s41524-025-01761-9), [AiiDA-TrainsPot](https://pubs.rsc.org/en/content/articlelanding/2026/dd/d6dd00005c), [2026-06 프리프린트](https://arxiv.org/abs/2606.22234)

**약물: 공결정 예측이 애매해지는 실제 사례를 검증하기**

공결정은 분자 A와 B 하나씩이 잘 붙는 것 이상의 문제다. 두 성분의 원래 결정, 다양한 배좌와 결합 자세, 용매·혼합비·결정화 방법이 경쟁한다. 2013년 연구는 이미 결정 격자 에너지와 결정구조 탐색을 사용했고, 파라세타몰(아세트아미노펜)–벤조산/안트라닐산의 미형성 사례도 다뤘다. 이들은 실패 사례를 읽는 출발점이지 새로운 반례가 아니다. [원논문](https://pubs.rsc.org/en/content/articlehtml/2013/ce/c3ce40107c)

최근 연구는 “성공 사례가 많이 남고 실패 기록은 부족하다”는 데이터 문제를 다룬다. 2026년 JCIM 논문은 신뢰할 만한 가상 음성 사례를 고르는 준지도 학습을 제안했다. 2025년에는 분자 열역학과 용매 정보를 결합한 모델도 발표됐다. 따라서 음성 데이터나 용매를 넣는다는 발상 자체를 신규성으로 삼을 수 없다. [2026 JCIM](https://pubmed.ncbi.nlm.nih.gov/42503654/), [2025 열역학 결합 모델](https://onlinelibrary.wiley.com/doi/10.1002/anie.202502410)

또한 DFT가 추가되면 반드시 예측이 좋아진다는 가정은 성립하지 않는다. 2025년 GIN-Mordred 비교 연구에서는 그 연구가 평가한 DFT 유래 특징 기반 접근보다 그래프·분자 기술자 모델이 더 나았다. 모든 DFT 방법이 열등하다는 증거는 아니지만, 우리도 계산 비용 대비 추가 정보를 입증해야 한다. [비교 원논문](https://pubs.acs.org/doi/10.1021/acs.cgd.5c00347)

가장 구체적인 시작점은 DeepCocrystal의 2025년 디플루니살 실험이다. 아래 네 조합은 보고된 성공/미형성 결과와 예측 불확실성을 함께 비교할 수 있다. 미형성은 논문의 실험 조건 아래 관찰이며 모든 조건에서 불가능하다는 뜻이 아니다. [원논문 Table 3](https://pmc.ncbi.nlm.nih.gov/articles/PMC12258686/)

| 약물 | 공형성제 | 보고된 실험 결과 | 파일럿에서 묻는 것 |
|---|---|---|---|
| 디플루니살 | 아데닌 | 공결정 형성 | 이종 결합 모티프와 자기 결합의 경쟁 |
| 디플루니살 | 카페인 | 공결정 형성 | 유사 퓨린계 분자와의 차이 |
| 디플루니살 | 테오브로민 | 해당 실험에서 미형성 | 예측이 불확실했던 조합에 DFT가 정보를 주는가? |
| 디플루니살 | 잔틴 | 해당 실험에서 미형성 | 배좌·양성자 위치·용매·자기 결합으로 설명 가능한가? |

이 네 건의 재분석은 알려진 결과를 이용한 사후 검증이다. 블라인드 검증이나 새 공결정 발견으로 보고하지 않는다. 아세트아미노펜은 작은 분자 최적화 연습으로 유지하고, 연구용 약물은 이런 실험 근거가 있는 대상으로 바꾸는 것이 합리적이다.

제안하는 첫 계산과 비교는 다음과 같다.

1. 논문·보충자료에서 분자 형태, 혼합비, 용매, 방법, 온도, 시간, 고체 판정 방법을 추출한다. 빠진 항목은 추정해 채우지 않고 미보고로 남긴다. 결정구조가 공개돼도 용액 내 초기 배좌와 같다고 가정하지 않는다.
2. 단량체의 서로 다른 배좌·호변이성질체 가능성과 전하 상태를 확인한다. RDKit/xTB는 시작점 생성에 쓰고, DFT 최적화와 최소점 검증을 별도로 한다.
3. A–B뿐 아니라 A–A와 B–B의 여러 결합 자세를 계산한다. r2SCAN-3c를 시작 방법으로 검토하고 중요한 순위는 방법 민감도를 확인한다. 임의의 분산·기저 보정을 중복 추가하지 않는다.
4. `ΔE_exchange = E(AB) − ½E(AA) − ½E(BB)`를 자기 결합과의 경쟁 지표로 사용한다. 이는 `½AA + ½BB → AB`의 전자 에너지 차이이며 공결정 형성 자유에너지가 아니다. 같은 조성·전하·방법·용매 조건을 유지하고 자세별 분포를 보고한다.
5. 문헌의 실제 용매에 대응하는 연속체 모델로 민감도를 조사한다. 연속체가 특정 용매 분자의 수소결합·핵생성 과정을 다 설명한다고 가정하지 않는다. 용매 모델만 바꿔 순위가 뒤집히면 판정을 보류한다.
6. 간단한 분자 기술자·수소결합 특징과 공개 예측 모델을 기준선으로 두고 DFT가 무엇을 추가했는지 비교한다. 같은 시험 사례·같은 평가 분모에서 비교하며, 네 사례로 모델을 학습하거나 전체 정확도를 주장하지 않는다.

확장 목표는 3개 이상 약물의 12~20조합을 먼저 확보하고, 데이터·자원이 충분할 때 늘리는 것이다. 숫자는 통계적 검정력 계산에서 나온 것이 아니라 실행 가능한 파일럿의 제안 상한이다. 어려운 사례만 고른 패널은 전체 스크리닝의 성공률을 대표하지 않는다. 배좌 수, 원자 수, 힘 계산 횟수가 비용을 결정하므로 실제 단량체와 복합체 1건씩 측정한 후 범위를 고정한다.

독립적인 예측 평가로 확장할 때는 동일 분자쌍·SMILES 변형·약물의 중복과 사전학습 중복을 먼저 확인한다. 공개된 고정 모델이 이미 본 사례는 독립 시험으로 부르지 않는다. 가능하면 약물 단위로 분리해 비교하고, 표본이 적으면 효과 크기·불확실성·개별 실패 원인을 제시한다. 동일 약물의 많은 배좌를 독립 표본처럼 세지 않는다. 실패한 계산도 분모에 포함한다.

후속 데이터 후보로는 2022년 프라지콴텔의 30공형성제 비교 실험이 있다. 서로 다른 결정화 방법을 비교하므로 조건에 따른 판정 차이를 읽기 좋다. 다만 더 큰 분자와 입체화학 때문에 첫 DFT 대상보다는 데이터·방법 검토용이 적절하다. [저자 기관의 원문·메타데이터](https://strathprints.strath.ac.uk/81899/)

기여 후보는 (a) 출처·조건을 추적할 수 있는 실패 사례 자료, (b) 저렴한 모델이 불확실한 영역에서 DFT가 유용해지는 조건, (c) 그 효과가 다른 약물에서도 반복되는 독립 검증이다. DFT를 추가해도 개선되지 않는다면 “이 설정과 사례에서 추가 계산의 이점이 없었다”는 결과로 남긴다. 충분한 범위와 검증 없는 부정 결과가 자동으로 출판 가치가 생기는 것은 아니다.

**10주 계획의 수정 제안과 진행 기준**

두 분야 모두 기초를 배우되, 10주 안에 두 편의 독립 연구를 완성한다는 목표는 두지 않는다. 계산 속도보다 연구 질문과 검증 자료를 먼저 확정한다.

| 주차 | 할 일 | 다음 단계로 가는 조건 |
|---|---|---|
| 1–2 | 기존 물·아세트아미노펜 최적화/진동과 MoS₂ 기준 계산 학습. 동시에 약물 4조합의 실험 조건과 반도체 공개 기준 입력 확보 | 실제 최소점·수렴·시간 측정. 알려진 결과를 같은 의미로 비교할 수 있음 |
| 3–4 | 약물 4조합의 경쟁 결합 파일럿, 반도체 9점 기준 에너지 파일럿 | 계산 실패를 제외하지 않은 표와 방법 민감도. 선행연구와의 차이를 한 문장으로 설명 가능 |
| 5 | 주력 연구 하나를 선택하고 사례·평가 규칙 고정 | 약물은 조건과 결과의 출처 확보, 반도체는 관심 차이를 분해할 정밀도 확보. 기존 기준선보다 추가 정보가 생길 근거 |
| 6–8 | 주력 분야의 독립 사례 확장. 다른 분야는 기준 계산 재현과 해석을 계속 학습 | 선택한 사례만 사후 보고하지 않고 전체 성공·실패 기록 유지 |
| 9–10 | 방법 민감도·독립 검증·그림·재현 가능한 결과 묶음 | 지지된 주장, 반박된 가설, 미해결 항목을 구분한 보고서 |

| 상황 | 선택 |
|---|---|
| 약물의 실패 조건을 확보할 수 없다 | 무조건 미형성으로 라벨링하지 않는다. 공개 결정 구조의 결합 모티프·에너지 재현으로 범위를 줄인다 |
| DFT 경쟁 결합이 다른 약물에서 추가 정보를 주지 않는다 | 대량 이합체 계산을 중단하고, 결정 패킹 자료 또는 실험 협업이 필요한 질문으로 전환한다 |
| 반도체의 차이가 수치·함수 민감도보다 작다 | 모델 오류 주장을 보류하고 수렴 재현 과제로 마친다 |
| 모델의 합금 적용 자체가 지원되지 않는다 | 적용 범위 밖 실패를 과장하지 않는다. 지원되는 조합의 재현 또는 별도 데이터 기여로 목표를 재정의한다 |
| 두 파일럿 모두 새 질문으로 이어지지 않는다 | 설치·학습 결과를 보존하고, 공개 실험 자료가 풍부한 다른 분자/계면으로 바꾼다 |

**학계에 전달할 수 있는 결과물의 형태**

반도체라면 다른 연구자가 모델을 시험하는 데 바로 쓸 수 있는 구조·에너지·힘·수렴 근거 묶음이다. 약물이라면 성공/실패를 실험 조건과 연결한 사례표, 복수 결합 자세의 계산, 기준선 대비 추가 정보와 실패 원인이다. 공개 저장소에 데이터가 있다는 사실만으로 재배포 범위가 같다고 가정하지 않고, 원자료의 사용 조건과 자체 생성 결과를 구분한다.

연구 협업이 가능해지면 계산이 제안한 차이를 XRD·열분석·분광 또는 고체 물성 실험으로 검증하는 경로가 강해진다. 현재는 협업이나 실험 접근성이 확보됐다고 가정하지 않는다. 이번 조사에서는 연구자에게 연락하거나, 모델을 설치·실행하거나, 새 후보 계산을 시작하지 않았다.

**조사 범위와 한계**

2024–2026년 원논문·저자 저장소를 중심으로 조사하고, 중복 확인과 기준 실험 확보를 위해 2013·2018·2022년 자료를 포함했다. 날짜는 가능한 경우 온라인 출판일과 권호 날짜를 구분했다. 2026-06 MACE 논문은 프리프린트로 표시했다. 일부 출판사 원문·첨부는 도구 접근이 불안정해 검색에 노출된 출판사 본문, 공개 초록, 저자 전신으로 보완했다. 이는 체계적 문헌고찰이나 모든 학위논문·특허·미공개 연구를 확인한 신규성 보증이 아니다.
