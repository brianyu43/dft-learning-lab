# 2주차 실행 계획과 판정 기준

2026-09-10. 사용자가 2주차 준비·실행을 요청했다. 1주차 원시 결과는 보존한다. 이번 실행은 첫 비용 측정과 기준 정밀도 확인이며 3주차 전체 약물 DFT/이종 이중층 행렬은 포함하지 않는다.

**약물**

5종의 호변이성질체 후보와 결합 그래프를 검토하고 시드 17/43/89의 배좌를 만든다. 디플루니살의 방향족 카르복실산·페놀 표현, 카페인의 중성 케토 표현으로 첫 비용 측정을 진행한다. 다른 상태는 목록에서 삭제하지 않고 초기 선별 결과·상태 유지 여부와 함께 기록한다. 아데닌·잔틴의 N–H 위치와 양성자 이동 후보는 별도 상태로 다룬다.

첫 DFT 묶음은 디플루니살 단량체, 카페인 단량체, 디플루니살–카페인 이합체 1자세다. r2SCAN-3c/TightSCF/TightOpt, 진공, 전하 0, 단일항, 직렬 실행이다. 단량체·이합체 최적화와 진동을 구분해 실제 비용을 잰다. 최소점이 검증돼도 한 자세의 결과는 네 사례의 순위·공결정 형성 판정에 사용하지 않는다.

나머지 이종 3종과 동종 5종에도 같은 기하 생성 규칙으로 초기 자세를 준비한다. 수소결합·방향족 접촉을 포함하며 분자쌍마다 최대 48개 시작점, 후속 DFT 최대 3개 원칙을 유지한다. 선별은 결과 라벨을 사용하지 않는다. 양성자 이동·결합 변화·분리·중복을 기록한다. 여러 중요한 상태가 3개 한도를 넘으면 다음 단계의 상태 범위를 명시적으로 수정한다.

최종 보충자료와 미형성 시도별 조건의 미확정은 유지된다. 이 결측은 진공 비용 측정을 막지 않지만 실험 실패 원인 해석을 막는다. 에탄올 모델·자기 결합 경쟁 점수의 전체 평가는 아직 수행하지 않는다.

**반도체**

1주차 MoS₂ 최종 원자 좌표와 a=3.18 Å를 고정한다. PseudoDojo nc-sr-04 PBE scalar NC + vdW-DF-C09를 유지한다. 원문과 정확한 퍼텐셜 파일 일치는 미확인이다. 모든 진공 값은 외측 S 평면 사이 주기 이미지의 빈 간격이다.

먼저 세 축을 한 번에 하나씩 바꾼다. 기준은 120 Ry, k=12×12×1, 진공 30 Å, 전자 수렴 1e-10 Ry다.

| 축 | 값 | 나머지 고정값 |
|---|---|---|
| 파동함수 cutoff | 80, 100, 120 Ry | k=12, 진공 30 Å |
| k-grid | 6, 9, 12 | cutoff 120 Ry, 진공 30 Å |
| 진공 간격 | 20, 25, 30 Å | cutoff 120 Ry, k=12 |

전하밀도 cutoff는 파동함수의 4배다. 중복 기준점을 공유하므로 첫 묶음은 7개 SCF다. 가장 엄격한 계산을 절대 진실로 가정하지 않는다. 인접한 가장 엄격한 두 점의 에너지 변화 1 meV/atom 이하, 힘 변화 0.005 eV/Å 이하를 단층의 출발 기준으로 정한다. 낮은 비용 조합을 선택하면 조합을 합친 설정에서도 다시 확인한다. 기준을 못 맞추면 해당 축을 한 단계 확장하거나 정밀도 미확정으로 남긴다.

순수 MoS₂/MoS₂ 6원자 이중층은 같은 고정 면내 격자, R-type(같은 방향)의 기준 대조다. 상대 이동은 원시 셀 벡터 기준 (0,0), (1/3,2/3), (2/3,1/3)이다. 우선 Mo 평면 거리 6.3 Å에서 세 이동을 비교하고, 기준 위치의 6.0/6.3/6.6 Å를 확인한다. 경계가 최저이면 평형 거리를 확정하지 않는다. 대칭으로 동등해야 하는 두 이동의 차이도 검증한다.

층간 에너지는 같은 셀·동일 좌표의 분리층 두 계산을 빼고 면적으로 나눈다. 재사용은 입력 해시가 같은 경우에만 한다. 단층 수렴이 층간 에너지 수렴을 보장하지 않으므로 대표 이중층/분리층에서 최종 두 설정의 차이가 0.1 meV/Å² 이하인지 확인한다. 아직 MoSe₂/합금에 이 정밀도를 일반화하지 않는다. 평형 면내 격자와 포논 안정성은 별도 항목으로 남긴다.

**운영**

동시 계산 1개, QE OpenMP 4/BLAS 1, ORCA 직렬을 유지한다. 개별 연구 계산은 최대 12시간, 프로세스 트리 RSS 기준 40 GiB다. 이번 묶음은 약물 6시간·반도체 4시간을 중간 검토 지점으로 삼으며 4주 전체 80/40시간 예산에 누적한다. 시간 기준을 넘으면 결과를 정리해 범위를 재평가한다. 실패를 자동 반복하지 않는다.

모든 시도는 입력·설정·난수 시드·출력·버전·해시·시간·실패 이유를 남긴다. 파서/단위 검증 오류는 엔진 실패와 구분한다. 문헌 원문, 1주차 생성 구조, 이번 생성 구조와 실제 계산 결과를 분리해 보관한다.

방법 근거: [ORCA 3c 방법](https://www.faccts.de/docs/orca/6.1/manual/contents/modelchemistries/3cmethods.html), [xTB 최적화](https://xtb-docs.readthedocs.io/en/latest/optimization.html), [층내/층간 분리 계산의 원 논문](https://arxiv.org/html/2503.15432v1). 위 수치 판정 기준은 이번 파일럿의 운영상 선택이다.

## 실행 중 운영 검토: xTB 반복 한도

이합체 91/412개 시점에서 3회 연속 미수렴 중단 규칙이 작동했다. 당시 누적 미수렴 6개는 모두 정상 종료·SCC 수렴 후 구조 최적화 반복 한도(219회 또는 258회)에 도달했다. 해당 실패 유형을 검토한 뒤 모든 미수렴 후보를 제외 상태로 보존하고 아직 실행하지 않은 후보를 이어가기로 했다. 수렴 조건과 에너지 선택 기준은 유지했다. 같은 입력의 재실행은 없고, 예상 밖 엔진/SCC 실패 3회 연속 중단과 시간·메모리 상한은 유지한다.

검토 근거는 `experiments/week2/xtb-continuation-review.json`, 중단 당시 요약은 `runs/week2-xtb-dimers/batch_before_reviewed_continuation.json`에 있다. 최초 실행 코드와 수정 실행 코드는 각각 별도 스냅샷으로 남겼다. 이 운영 변경은 최적화 미수렴을 성공으로 바꾸지 않는다.
