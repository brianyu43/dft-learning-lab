# 약물 B/X 집계 규칙과 검증 범위

2026-09-29. `scripts/completion_drug_contrasts.py`는 공통 조건에서 이미 검증된 에너지를 전달받아 B/X와 교차 순위를 계산하는 산술 모듈이다. 현재 연구 패널의 점수를 산출하거나 원시 결과를 승인하는 실행기가 아니다. 원시 결과 연결 도구는 별도 [전체 패널 검증 절차](DRUG_FULL_PANEL_VALIDATION.ko.md)에 구현했으며 실제 공통 패널 계산은 아직 미완료다.

## 입력에 필요한 과학적 검증

호출자는 입력·출력·구조 해시, SCF/기하 수렴, 전체 내부 진동과 Hessian 좌표, 화학적 상태, 공통 수치 설정을 원시 파일에서 검증해야 한다. 단일점 방법 비교는 검증된 모체 최소점과 동일 좌표라는 근거를 추가한다. 용매 최적화에는 해당 환경의 최소점 검증이 필요하다. 검증되지 않은 결과를 이 함수에 넣고 숫자가 나온다는 이유로 승인하지 않는다.

집계 묶음마다 `method`, `environment`, `numerical_protocol_id`, `energy_quantity`를 고정한다. 네 필드 중 하나라도 다른 입력을 혼합하면 오류로 중단한다. 전자 에너지와 ZPE 보정량은 따로 집계한다. SMD 계산의 에너지에 포함된 연속 용매 항도 원시 출력에서 정의하고 진공 에너지와 같은 물리량인 것처럼 섞지 않는다. 같은 이름의 수치 프로토콜이라는 주장만으로 실제 적용 검증을 대신하지 않는다.

각 입력에는 `record_id`, `species`, `selection_role`, `energy_Hartree`, `comparison_context`가 필요하다. `selection_role`은 원래 고정된 시작점 정책의 primary/alternative 대응으로 결정한다. 정밀도 재계산은 원래 시작점의 역할을 물려받으며 새 독립 자세로 세지 않는다. 현재 이 대응과 원시 출력 검증을 갖춘 전체 패널 연결은 미완료다.

## 산술과 판정

- `B = E(AB) − E(A) − E(B)`
- `X = E(AB) − ½E(AA) − ½E(BB)`
- 단위 변환은 기존 프로젝트와 같은 627.509474 kcal/mol per Hartree를 사용한다.
- 기본 시작점만의 결과와 선택된 전체 자세 결과를 따로 계산한다. 각 종류의 최저 전자 에너지를 선택하며, 나머지 자세와의 간격·사용한 기록·기록 수를 함께 반환한다. 기록 수는 고유 최소점이나 독립 표본 수가 아니다.
- 성분이 없으면 해당 점수는 `null`이며 누락된 종류를 남긴다. 계산 실패를 미형성 예측으로 바꾸지 않는다. B의 세 성분이 있어도 자기 결합 대조가 없으면 X는 미산출로 남는다.
- 양성 아데닌/카페인과 미형성 테오브로민/잔틴의 교차 비교 네 건을 모두 보고한다. `Δ = score(미형성) − score(형성)`이 양수면 알려진 관찰과 같은 방향이다. 공통 분자가 있으므로 네 비교는 독립 반복 실험 네 회가 아니다.
- 동률 폭은 사전에 정한 0/0.5/1/2 kcal/mol을 전부 사용하고, 경계와 같은 차이는 동률이다. 기계 반올림을 위한 1e-8 kcal/mol 경계 여유는 과학적 수치 오차 추정값이 아니다. cutoff/적분 격자/SCF 변화로 추정하는 실제 수치 민감도는 별도로 보고한다.

공통 DIF–DIF 에너지의 같은 오프셋은 모든 X를 같은 양만큼 이동시키므로 X 사이의 순위 차이에서는 소거된다. 이는 절대 X에 자기 결합 대조군이 불필요하다는 뜻도, 다른 구조·설정의 정밀도 검증을 생략해도 된다는 뜻도 아니다.

## 이번에 확인한 범위

9개 점검을 통과했다. 대부분은 답을 손으로 구할 수 있는 합성 에너지 또는 에너지 기준의 이동에도 결과가 불변이어야 한다는 성질을 사용한다. 실제 데이터 확인은 이미 완료한 고정 좌표 DIF/DIF–DIF 진단의 g3–dense 자기 결합 차이 0.00474413 kcal/mol을 재현한 한 항목이다. 네 공형성제 패널이나 새로운 최소점이 완료됐다는 근거는 아니다.

검증에는 올바른 B/X 계수, 분자별 에너지 원점 이동의 소거, 누락된 자기 결합 대조 처리, 동률 경계와 판정 불가, 기본/추가 자세 분리, 방법·환경·격자·에너지 종류 혼합 거부, NaN/무한대/불리언 거부, 공통 자기 결합 기준의 순위 불변성, 기존 진단 값 재현이 포함된다.
