# 3주차 실행 범위와 해석 기준

2026-09-11. 사용자의 3주차 진행 지시에 따른 실행 기록. 1·2주차 입력과 결과는 보존한다.

## 약물

질문은 고립 분자쌍의 접촉 자세와 자기 결합 대조가 에너지 비교를 어떻게 바꾸는가이다. 실제 공결정의 다형을 열거하거나, 그 형성 자유에너지를 구하는 실험은 아니다.

정식 논문의 보충 PDF를 Europe PMC supplementaryFiles 경로에서 확보했다. 19쪽 전체 텍스트를 확인하고 PDF 3·15–19쪽을 렌더링하여 검토했다. 공급원은 DOI 10.1002/anie.202507835의 정식판 SI이며, 기존 전신 원고와 구분한다. 파일 SHA-256은 `684edf33c16e0641481c50d6dcf4eda6af7942f45189f31989d7988c60a2dc0d`다.

SI p3의 실험법과 p16의 실제 그림 제목을 대조했다. p3 본문은 그림 S34/S33을 순서대로 열거하지만 실제 S33은 DIF–CAF, S34는 DIF–ADE다. 합성 투입비는 각 1:1이다. 이는 회절로 결정 화학량론을 확정했다는 뜻이 아니다. SI p15는 SSNMR의 단일 신호 패턴으로 비대칭 단위에 각 성분 하나를 추론한다. 본 자료에서 DIF–CAF/ADE의 CIF, 단위셀·공간군·다형 목록은 확인하지 못했다. Fig. S35의 CSD XOBcat/UWAFEM 구조는 살리실산 비교 사례이며 디플루니살 결정 좌표가 아니다.

CAF는 카르복실산 C 신호 175.2→172.9 ppm과 고리 N9 신호 230.0→221.1 ppm의 이동으로 COOH···N 접촉을 제안한다. ADE는 카르복실산의 양성자가 N1로 이동하고 N10 아미노기와 함께 고리형 접촉을 만드는 해석을 제안한다. 이는 원자의 실제 3차원 좌표를 제공하지 않는다. 미형성 두 조합의 시도별 조건과 반복 수는 여전히 미보고로 남긴다. 외부 시험 세트 일반 설명의 최소 3회 반복을 이 네 전향적 사례에 자동 적용하지 않는다.

첫 계산은 수소결합형 출발점 p14의 12프로세스 r2SCAN-3c/TightOpt/TightSCF Opt+Freq다. p14의 접촉은 페놀 OH–카페인 카르보닐이며 문헌의 COOH–N 접촉과 구별한다. 기존 p36은 xTB 최저 겹침형 출발점이다. 세 번째 CAF 슬롯은 원 계획의 선택적 p39 대신, 문헌이 제안한 COOH–N9 접촉을 유지한 후보 중 xTB 에너지가 가장 낮은 **p06**으로 고정한다. 이 변경은 p14의 DFT 결과를 보기 전에 문헌의 접촉 근거로 결정했다.

원자 대응은 0부터 시작하는 로컬 인덱스 기준이다. DIF 카르복실 OH의 O/H는 2/18, 페놀 O/H는 17/25다. CAF N9는 전체 이합체의 32번 원자다. ADE N1/N10은 전체 이합체의 28/26번 원자다. ADE 이온 시작점은 t06 상태의 **p36 원래 XYZ**에서 H18을 N1 쪽에 둔 것이다. xTB 최저 ADE p39의 이완 결과는 중성 상태로 돌아온 별도 후보로 사용한다.

남은 단량체 3종과 이합체 8종의 기본 대조군, ADE 직접 양성자 이동 시작점 1개, CAF 대안 2개를 합쳐 새 최적화 시작점은 총 14개다. p14 전체 시간·메모리와 검증 결과를 보고 후속 13개를 실행한다. 모든 새 ORCA 작업은 12 MPI·OpenMP 1, 최대 4시간, 프로세스 트리 RSS 40 GiB 제한이며, 연구 엔진은 한 번에 하나다. 프로젝트 약물 예산은 총 80시간, 2주차 후 75.8837시간이 남았다.

첫 묶음은 전체 Opt+Freq를 함께 실행한다. 같은 최소점에 도달해 Hessian이 중복되면 비용을 숨기지 않고 중복 최소점으로 표시한다. 이 변경은 실행·검증을 단순화하는 운영 선택이며 표본 수를 늘려 세는 근거가 아니다. 에너지 비교는 기본 후보만의 B/X와 확보된 모든 자세의 B/X를 분리한다. 종류별 자세·상태 수가 다른 비교를 완전 탐색의 공정한 순위나 예측 정확도로 표현하지 않는다. 각 종류 최대 3개라는 원래 상한 안에서 후속 확장은 비용과 상태 검토 후 결정한다.

## 반도체

기존 MoS2 고정 격자 3.18 Å 자료를 보존하고, MoS2와 MoSe2 평형 면내 격자를 같은 C09/PseudoDojo 조건에서 구한다. 처음은 cutoff 120 Ry, rho 480 Ry, 12×12×1, 초기 진공 간격 30 Å, 전자 수렴 1e-10 Ry다. `vc-relax`의 `cell_dofree='2Dxy'`로 z 셀 벡터를 고정하고, 최종 힘·육방 대칭·z 셀 보존을 독립 확인한다. 평형은 해당 근사와 주기적 셀 안의 결과이며 포논 안정성 검증은 아니다.

퍼텐셜 파일에서 Mo/S/Se 원자가 전자 수를 읽어 XML 전자 수와 비교한다. 특히 사용한 Se 파일은 16전자이며, S의 6전자를 복사해 적용하지 않는다. Se 단층에서 계산 설정 민감도를 다시 측정한 뒤 합친 설정을 검토한다.

두 평형 면내 격자의 산술 평균을 공통 격자로 고정하고 각 층의 변형률을 기록한다. 공통 격자에서 각 단층의 내부 z 좌표를 이완한 후 이종 이중층을 생성한다. R-type r0의 층간 거리를 최소점 양쪽의 에너지 상승이 확인될 때까지 제한된 범위에서 탐색한다. 기준 D0를 고정한 뒤 3개 상대 위치 × D0±0.25 Å의 9점과 같은 좌표·셀의 분리층 기준을 계산한다. 기준점이 경계에 있거나 정밀도 차이가 허용 범위를 넘으면 본 표를 확정하지 않는다.

MoS2의 기존 거리 탐색은 6.6 Å에서 경계 최소였으므로 추가 거리로 완성한다. 이 값은 이종 이중층 D0로 재사용하지 않는다. 24원자 계면/외측 교환 본 비교와 방법·용매 민감도는 다음 단계다.
