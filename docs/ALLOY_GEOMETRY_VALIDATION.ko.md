# 24원자 비교 구조와 내부 이완 제약의 구현 검증

2026-09-29. 기존 프로토콜 S1의 구조 정의를 구현했다. 이 문서의 수치와 그림은 **입력 생성·제약 코드의 시험 결과**이며 재료의 DFT 에너지나 평형 구조 결과가 아니다. 실제 계산은 기준 9점의 정밀도·비용 확인 후 별도로 진행한다.

## 구현과 확인한 범위

`scripts/completion_alloy_geometry.py`는 같은 면내 셀을 가진 MoS₂/MoSe₂ 3원자 단층을 받아 원시 벡터의 상대 위치와 Mo 평면 거리로 6원자 이중층을 만든 뒤 2×2로 복제한다. 층·원시 원자·복제 타일 인덱스를 보존한다. 입력 단층의 원자 순서와 전체 평행이동에 의존하지 않도록 Mo/상부 칼코젠/하부 칼코젠 순서와 Mo 원점을 명시한다. 입력 파일 자체는 변경하지 않는다.

초기 교환 위치는 아래층·위층 모두 원시 타일 (0,0)이다. CI에서는 아래층 위쪽 S와 위층 아래쪽 Se를, CO에서는 아래층 아래쪽 S와 위층 위쪽 Se를 교환한다. CI/CO의 교환 원자는 각 층에서 같은 면내 좌표를 갖는다. C0/CI/CO의 전체 좌표·셀은 정확히 같고 원소만 바뀐다. 다른 위층 타일 선택은 후속 독립 배치 시험을 위한 함수 인자로만 제공하며, 이번 결과에 맞춰 선정하지 않는다.

- 총 조성: 세 구조 모두 Mo8S8Se8, 24원자.
- 층 조성: C0는 Mo4S8 / Mo4Se8, CI와 CO는 Mo4S7Se / Mo4SSe7.
- 상대 위치: 원시 셀의 (0,0), (1/3,2/3), (2/3,1/3). 초격자의 분수로 바꾸지 않는다.
- 거리: 위·아래 Mo 4개씩의 평균 z 차이. 진공은 가장 바깥 원자 사이의 비어 있는 셀 간격이다.
- 조성, 잘못된 면, 격자 불일치, 층 중첩, Mo 상대 이동, 원자 메타데이터 불일치는 거부한다.

예시 공통 격자 a=3.24 Å, 거리 6.45/6.70/6.95 Å, 진공 25 Å의 27개 구조를 생성하고 extxyz 저장·재읽기를 검증했다. 이 a와 거리는 실행 중인 최적화에서 얻은 값이 아니다. 구조들은 `structures/completion/geometry-fixtures/`에 `fixture_only=true`로 저장했다. 연구 엔진 입력으로 등록하지 않았다.

## CI/CO 대칭 비동등성

S와 Se를 같은 원자 종류 X로 보는 Mo/X 모구조의 전체 공간군 연산을 spglib 2.7.0으로 구했다. 각 연산을 이중층 전체에 적용하고, 실제 Mo/S/Se 원소와 주기 좌표를 보존하는 일대일 원자 대응이 존재하는지 검사한다. 한 층만 뒤집는 연산은 전체 결정의 대칭으로 취급하지 않는다. 원자 순서, 주기적 좌표 감기, 전체 원점 이동을 허용한다. 모구조 자체가 다른 두 구조는 이 검사에 넣지 못한다.

9개 위치·거리와 1e-5/1e-4/1e-3 Å 허용 오차 모두에서 모구조 연산은 각각 24개였고, CI를 CO에 대응시키는 연산은 없었다. 같은 CI 구조의 원자 순서·원점·주기 표현을 바꾼 양성 대조는 동등 판정을 받았다. 교환 타일을 달리한 구조를 Cartesian 좌표에서 120도 회전시킨 별도 양성 대조도 비항등 회전 연산을 통해 동등 판정을 받았다. 실제 최종 기준 구조에서도 같은 검사를 다시 수행해야 한다. [spglib의 분수 좌표 연산 정의](https://spglib.readthedocs.io/en/v2.7.0/api/autodoc/spglib.spg.html)

## 내부 좌표 이완 제약

`FixMoLayerCentroids`는 각 층의 Mo 중심 (x,y,z)을 각각 고정하는 6개의 선형 제약이다. 두 중심의 차이를 보존하므로 Mo 평균 층간 거리와 상대 위치가 고정된다. 개별 Mo의 내부 이동과 S/Se 원자의 이동은 허용한다. 전체 셀은 고정하며, 최적화 도중 좌표를 개별적으로 주기 경계 안으로 감지 않는다.

위치 보정은 해당 Mo 그룹에만 적용하고, 힘에서 해당 그룹의 평균 성분을 제거한다. 설치된 ASE 3.29.0의 `FixSubsetCom.adjust_positions`는 위치 보정을 전체 원자 배열에 더하므로 이 기능을 두 층에 순서대로 사용하는 방식은 채택하지 않았다. 이 프로젝트의 제약은 독립 구현이며, 저장/복원은 명시적 `todict/fromdict`를 사용한다. ASE의 일반 제약 이름 등록기에 자동 등록된 것으로 가정하지 않는다. [ASE 사용자 제약 인터페이스](https://docs.ase-lib.org/ase/constraints.html)

원자별 강성이 다른 조화 퍼텐셜에서 해석적으로 구한 제약 최소점과 실제 ASE BFGS 결과를 비교했다. 시험의 초기 Hessian 척도는 해당 퍼텐셜의 강성에 맞춰 1 eV/Å²로 설정했다. 이는 향후 QE 이완의 최적화 설정을 고정하는 결과가 아니다.

| 검증 항목 | 측정 결과 |
|---|---:|
| BFGS 수렴 단계 | 17 |
| 전체 궤적의 최대 Mo 중심 이동 | 3.553e-15 Å |
| 해석적 최소점과 최대 좌표 오차 | 3.477e-9 Å |
| 셀 변화 | 0 Å |
| 실제 내부 원자 최대 이동 | 0.4220 Å |
| 최종 투영 힘 최대값 | 7.440e-9 eV/Å |
| 최종 원래 힘 최대값 | 0.2983 eV/Å |

원래 힘이 남는 것은 고정한 방향의 반력이다. 향후 제약 이완에서는 허용 방향으로 투영한 힘의 수렴과 원래 힘을 둘 다 보고해야 한다. 원래 힘이 0인 자유 최소점이라고 표현하지 않는다. 100번의 임의 위치 갱신, 허용 방향의 에너지 유한차분과 투영 힘 비교, 저장·복원, 원자 순서 변경도 확인했다. 제약된 구조를 잘라 제약이 조용히 사라지는 동작은 거부한다. 분리층 기준은 제약을 붙이기 전에 추출한다.

## 실행 전 남은 항목과 재현

현재 통과한 것은 **12개 소프트웨어/입력 검증**이다. 실제 기준 단층·D0로 27개 입력을 만들고 다시 검사해야 하며, 24원자 비용 실측과 수치 정밀도 판정도 남아 있다. 추가 내부 이완 9개는 QE와 ASE 사이의 실제 좌표·에너지·힘·단위 전달, 원래 힘과 투영 힘의 기록, 거리/상대 위치/셀 보존, 비용 조건을 검증한 뒤에만 실행한다. 이번 조화 시험은 QE 검증을 대신하지 않는다.

```sh
.venv/bin/python scripts/validate_completion_alloy_geometry.py
```
