# 24원자 본 비교에 앞선 비용 측정 준비

2026-09-29. `scripts/prepare_completion_alloy_probe.py`는 검증된 공통 격자 단층과 층간 거리 D0를 받아 후속 비교를 준비한다. **현재 기준 배치는 실행 중이며, 실제 24원자 입력 생성·QE 실행은 아직 0건이다.** 이 문서는 준비 절차와 검사 결과를 설명한다.

## 기준값의 출처

준비 함수는 `reports/week3-materials.json`이 `passed`여야 다음 단계로 진행한다. 요약의 통과 표시만 믿지 않고, 두 평형 단층과 공통 격자 단층의 원시 출력/XML·최종 힘·격자·수렴·C09 설정 및 의사퍼텐셜을 다시 읽는다. 평형 격자의 산술 평균과 실제 공통 격자·변형률을 대조한다.

이종 이중층 9점, D0의 힘 부호 변화 양끝 및 엄격한 수치 설정의 대표점을 원시 SCF로 재검사한다. 분리층의 좌표·셀과 계산 조건, 실제 상대 위치·거리·면적, 층간 에너지와 힘을 확인한다. 0.1 meV/Å² 기준을 임의로 완화하지 않는다. 실제 완료 기준 자료가 아직 없으므로 이 전체 경로의 실제 자료 통합 검증은 기준 배치 완료 후 수행해야 한다.

## 준비하는 구조와 계산 수

메모리에서 C0/CI/CO × 상대 위치 3개 × 거리 3개로 27개 비교를 구성한다. 두 분리층은 매 이중층의 해당 원자 인덱스를 그대로 추출하며, 따로 중심을 맞추거나 주기 좌표를 접지 않는다. CI와 CO의 대칭 비동등성도 생성한 구조에서 다시 검사한다.

재사용 키에는 실제 원소 순서·좌표·셀·주기성, 공통 prefix로 직렬화한 QE 입력 해시, 수치 설정, 의사퍼텐셜 및 실행 파일 해시를 포함한다. 미세한 좌표 차이를 반올림해 같은 구조로 합치지 않는다. 작업 이름에 필요한 prefix만 재사용 판단에서 제외한다.

2×2 초격자의 k-grid는 원시 셀 k의 절반을 올림한다. 6→3, 9→5, 12→6이며, 9→5는 원시 셀 환산 10이다. 간격을 더 성기게 하지 않는 선택이지만 원래 적분점과 완전히 같다는 뜻은 아니다. 합금 비교의 별도 수치 민감도 검사는 여전히 필요하다.

실행 가능한 첫 배치는 **CI/r0/D0 이중층 1건과 해당 분리층 2건**으로 한정한다. 각 작업은 최대 1시간, 배치 상한 3시간, QE OpenMP 4·RSS 40 GiB이며 기존 단일 엔진 제어기를 사용한다. 이는 예상 시간이 아니라 중단 상한이다. 27개 전체 비교의 계획표는 포함하되 나머지 실행 입력은 만들지 않는다.

첫 3건의 실제 에너지·힘·소요 시간·최고 메모리를 검증한 뒤 남은 반도체 예산에 맞춰 본 행렬 진행 여부를 기록해야 한다. 24원자 이완 9개와 방법 민감도에는 별도 검토가 필요하다. 3건 비용 측정을 본 비교 완료로 세지 않는다.

## 검사 범위

6개 검사를 통과했다. 미완료 기준에서 파일 쓰기 차단, 정밀도 실패 표시 거부, 초격자 k 간격, 27개 비교의 정확한 분리층 추출, 동일 입력만 재사용, 실제 QE 입력 직렬화 후 좌표·셀·조건의 일치를 확인했다. 검사에 사용한 a=3.24 Å·D0=6.7 Å는 예시이며 생산 계산의 기준값이 아니다.

검사 명령:

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_completion_alloy_probe.py' -v
```

기준 배치가 통과한 뒤 준비 명령:

```sh
.venv/bin/python scripts/prepare_completion_alloy_probe.py
```

그때 생성되는 `experiments/completion/alloy-cost-probe-r1.json`의 출처·입력 해시를 검증하고, 엔진 잠금 해제와 실제 잔여 예산을 확인한 뒤 기존 제어기로 실행한다. 준비 스크립트는 계산을 시작하거나 실행 중인 작업을 중단하지 않는다.
