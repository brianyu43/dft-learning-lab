# 공통 약물 패널의 영점 보정 점수 집계 준비

2026-09-29. `scripts/completion_drug_zpe_panel.py`는 공통 r2SCAN-3c 최소점 17개의 전자 B/X와 영점 보정 보조 점수를 연결한다. **8개 합성 산술·검증 절차 검사를 통과했으며, 실제 공통 패널의 ZPE 점수 파일은 아직 없다.** [준비 기록](../reports/completion/drug-zpe-panel-preparation-r1.json), [검사 로그](../reports/completion/drug-zpe-panel-tests-r1.log).

## 비교량과 자세 선택

각 구조의 영점 에너지를 Z로 쓸 때, 같은 자세에서의 보조 변화는 다음과 같다.

\[
\Delta_{\rm ZPE} B = Z_{AB}-Z_A-Z_B,\qquad
\Delta_{\rm ZPE} X = Z_{AB}-\tfrac12Z_{AA}-\tfrac12Z_{BB}.
\]

주 분석은 기존의 **전자 에너지로 선택한 자세와 전자 B/X**다. 보조 분석에서는 기본 자세만 사용하는 범위와 모든 선택 자세를 사용하는 범위를 유지하며, 각각 두 결과를 기록한다.

- **전자 에너지의 선택 자세 고정:** 같은 자세에서 영점 보정을 추가한다.
- **전자+영점 에너지로 재선택:** 보조 기준으로 고른 자세를 명시하고, 그 자세의 전자 점수 변화와 영점 보정 기여를 분리한다.

두 번째 선택이 달라져도 원래 전자 분석을 바꾸지 않는다. 모든 보조 점수에 대해 동률 폭 0/0.5/1/2 kcal/mol의 판정을 기록하며, 네 분자쌍의 공유 성분으로 만든 비교를 독립적인 네 반복 실험으로 세지 않는다. 알려진 형성 여부는 비교표에만 사용하고 자세 선택 기준으로 쓰지 않는다. 대조군이 빠지면 null과 누락된 종 이름을 유지한다.

## 실제 자료를 연결하는 조건

공통 전자 점수 보고서가 있어야 집계를 시작한다. `completion_drug_panel.evaluate()`로 모든 dense/strict 원시 근거와 정밀도 기준을 다시 확인하고, 공통 최소점 17개의 실제 Hessian에서 ZPE를 읽는다. 기존 9개 과거 구조의 ZPE를 새 공통 패널 값으로 대체 사용하지 않는다.

진동수·스케일·좌표·원자 순서·전자 에너지와 ZPE 출력의 대응은 [기존 원시 추출기](../reports/completion/DRUG_ARCHIVED_ZPE.ko.md)로 확인한다. 이번 공통 패널은 스케일 1.0, H/C/N/O/F 질량 1.008/12.011/14.007/15.999/18.998 amu를 유지한다. 동위원소나 질량이 달라지면 비교 전에 검토한다. 모든 ZPE 값은 해당 구조의 전자 에너지와 같은 최소점에서 나온 것이어야 한다.

원래 전자 분석을 다시 계산한 결과가 부모 보고서와 정확히 같아야 하며, 모든 필요한 점수와 원시 해시가 확인된 경우에만 `reports/completion/uniform-vacuum-r4-zpe.json`을 생성한다.

```sh
# 실제 공통 전자 패널이 수치 검증을 통과한 뒤:
.venv/bin/python scripts/completion_drug_zpe_panel.py
```

출력은 전자 에너지의 수치 검증과 **진동수/Hessian의 격자 수렴**을 구분한다. 이번 보조 집계는 Hessian을 더 엄격한 격자로 재계산하지 않으므로 `frequency_grid_convergence_verified`는 false다. 온도·엔트로피·용매·결정 형성 자유에너지는 계산하지 않는다. 단일점 방법 변경과 용매 분석에는 각각 별도의 조건과 출처가 필요하다.

## 확인한 범위

합성 자료에서 B의 영점 보정이 정확히 0.003 Hartree, X의 보정은 0인 예제를 확인했다. 대안 자세 선택 때문에 전자 점수가 +0.3 kcal/mol 바뀌고 영점 기여가 −0.6 kcal/mol 바뀌는 경우도 두 항으로 분리했다. 이 숫자는 프로그램 검사용이며 실제 약물 결과가 아니다.

나머지 검사는 보정 후 순위 역전과 동률 판정, 빠진 자기 결합 대조군, 다른 방법·비유한 값·중복 ID·역할 변경, 질량 변경의 거부를 확인한다. 선행 파일이 없거나 `passed` 표기만 있고 원시 검증이 실패하면 새 점수 파일을 쓰지 않는다. 실제 17개 공통 결과를 통한 통합 실행은 계산 완료 후 확인해야 한다.

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_completion_drug_zpe_panel.py' -v
```
