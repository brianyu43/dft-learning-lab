# 반도체·약물 DFT 10주 작업 계획

작성일: 2026-09-09. 기준 장비: Apple M5 Pro, CPU 18코어, 통합 메모리 64 GiB, macOS 26.6.2, arm64. 주 8~12시간 학습·분석과 별도의 CPU 계산 시간을 가정한다. 시작일이 정해지지 않아 주차는 상대 일정으로 표시한다.

## 목표와 이번 작업의 범위

10주 목표는 두 분야의 기준 계산을 재현하고, 후속 검증할 후보를 분야별 1~3개 추리거나 탈락 이유를 제시하는 것이다. 신소재 발견·합성 가능성·공결정 형성·약효를 이번 계산만으로 확정하지 않는다.

이번 준비 작업에서는 도구 설치, 구조·입력 예제, 실행 기록 체계, 소규모 설치 검증까지 수행한다. 33개 반도체 조건과 약물 복합체 전체 탐색은 아래 단계에 따라 진행한다. 원문은 `docs/source/original-conversation.ko.txt`에 그대로 보존한다. 실제 완료 내용은 `reports/INSTALLATION.ko.md`와 실행별 `manifest.json`을 기준으로 확인한다.

매주 학습 2~3시간, 입력·해석 4~6시간, 검토·기록 2~3시간을 배분한다. 계산은 작은 작업 하나씩 시작하고 측정 후 병렬 수를 조절한다. 설치 검증만 통과했다고 1주차의 구조·진동 목표가 모두 달성된 것은 아니다.

## 계산 예산과 중단·수정 기준

- 처음에는 동시 계산 1개, OpenMP 4스레드, BLAS 1스레드를 기본값으로 한다. ORCA 직렬 예제의 `%maxcore 2000`은 코어당 MB 설정이며 프로그램 전체 메모리의 강제 상한이 아니다.
- 물/Si 설치 검증에는 각각 10분 제한을 둔다. 실제 약물·MoS2 최적화의 시간은 이 검증 결과만으로 추정하지 않고 별도 측정한다.
- 첫 실제 구조 최적화 2~3건을 바탕으로 밤사이 약 8~12시간 내 종료할 작업 규모를 정한다. 메모리 압박이나 swap 증가가 지속되면 작업을 멈추고 동시 수·구조 규모를 줄인다. 64 GiB 중 약 16 GiB 이상을 일상 사용 여유로 남기는 것을 운영 목표로 한다.
- 최적화가 반복 실패하면 SCF/힘/구조/의사퍼텐셜 원인을 먼저 확인한다. 반복 횟수만 늘려 전체 후보를 밀어 넣지 않는다.
- 비용이 과하면 0% 변형을 먼저 전수 계산한 뒤 상위 배열에 1/2% 변형을 적용한다. 33조건 계획에서 실제 계산한 수가 줄면 보고서에 이유·선택 규칙을 남긴다.
- 4주차 문헌 조사에서 연구 질문까지 이미 다뤄졌으면 해당 계열은 재현 실습으로 마무리하고, 계산량이 비슷한 대체 소재군을 검토한다. 데이터베이스 미등재는 신규성의 증거로 충분하지 않다.
- 유료 서비스·클라우드 GPU·대량 스크리닝은 이 설치 작업에 포함하지 않는다. 로컬 CPU 측정 결과를 보고 다음 계산 범위를 결정한다.

## 반도체 비교 규칙

단층은 2H 구조를 기준으로 시작한다. 생성된 MoS2·MoSe2 격자와 두께는 초기 추정치이며 재현 결과가 아니다. 모든 조성에 같은 함수·일관된 의사퍼텐셜 계열과 컷오프를 적용한다. 진공을 포함한 z 셀을 자유롭게 3차원 최적화하지 않는다. 면내 격자 탐색과 내부 좌표 최적화를 분리한다.

수렴 시험의 출발 목표는 에너지 변화 약 1 meV/atom 이하, 관심 밴드갭 변화 약 0.02 eV 이하, 최대 힘 약 0.01 eV/Å 이하이다. 이는 이 프로젝트의 제안 허용오차이며 달성한 값이 아니다. 수렴 곡선을 보고 확정한다. 진공 15/20/25 Å, k-grid 6/9/12(원시 셀 기준), 의사퍼텐셜 권장 cutoff의 1.0/1.25/1.5배를 출발 그리드로 검토한다. 2×2 셀은 같은 reciprocal-space 밀도를 기준으로 조절한다.

같은 Se 분율 x에서 배열 에너지는 동일 원자 수·동일 변형 정의로 비교한다. 평형 혼합 에너지는

`ΔE_mix / formula unit = E[Mo4S(8−n)Se(n)] / 4 − (1−x)E[MoS2] − xE[MoSe2], x=n/8`

로 기록한다. 기준물질 에너지는 화학식 단위당 값이며 같은 방법의 평형 구조에서 구한다. 변형 상태의 혼합 에너지를 구할 때는 끝점의 변형 조건도 명시한다. 개별 평형 격자 기준 변형과 공통 기판에 맞춘 coherent strain은 서로 다른 비교다.

Janus MoSSe는 알려진 기준 구조로 활용할 수 있으나 11개 배열에 자동으로 포함됐다고 가정하지 않는다. 비대칭 단층은 z 방향 쌍극자와 주기 이미지 상호작용을 점검하고 QE의 2D Coulomb cutoff 등 경계 조건을 문서화한다. SOC와 scalar-relativistic 결과를 섞어 한 순위로 만들지 않는다.

밴드갭은 한 고대칭 경로만으로 전 영역의 최솟값을 보장하지 않는다. 관심 후보에서 k-space 탐색을 보강한다. 작은 규칙 셀은 무질서 합금 전체를 대표하지 않는다. 유효질량은 충분한 주변 k점과 방향별 곡률로 추정하며 실제 이동도로 해석하지 않는다. 포논은 Γ 한 점으로 전체 안정성을 입증하지 않는다. 2D의 작은 음수 굽힘 모드는 수치 민감도와 실제 불안정성을 구별한다.

## 약물 비교 규칙

첫 단량체는 중성 singlet 아세트아미노펜(C8H9NO2, 수소 포함 20원자)이다. 니코틴아마이드·이소니코틴아마이드·요소·숙신산·푸마르산은 검토용 시작 목록이다. 조합의 선행 보고, 결정형, 화학적 형태와 양성자 이동 가능성을 4/7주차에 점검한다.

배좌 생성에서는 ETKDG 시드, 생성 수, RMSD 기준, MMFF/xTB 수렴·에너지를 기록한다. 대칭을 고려해 최적화 후에도 중복을 제거한다. 힘장 에너지 순위를 DFT 순위로 부르지 않는다. ORCA의 r2SCAN-3c에는 구성된 분산·기저 오차 보정이 포함되므로 임의의 D3/D4나 counterpoise를 중복으로 붙이지 않는다. 다른 방법의 BSSE 점검은 해당 방법에 맞게 따로 설계한다.

`ΔE_bind = E(AB, 최적화) − E(A, 분리된 최적화) − E(B, 분리된 최적화)`

는 분리된 최적화 단량체를 기준으로 하며 변형 비용을 포함한다. 고정된 복합체 기하에서 추출한 단량체를 사용한 interaction energy와 구분한다. 서로 다른 용매나 방법의 절대 에너지를 빼지 않는다. 전자 에너지 ΔE, 영점보정, 엔탈피 ΔH, 자유에너지 ΔG를 다른 열에 기록한다. 저주파·표준 상태·용매 모델 오차 때문에 고립 이합체의 조화 진동 ΔG를 용액·결정 형성 자유에너지로 단정하지 않는다.

SCF 수렴, 기하 최적화 수렴, 최소점 검증을 독립적으로 기록한다. 허수진동이 있으면 모드를 확인하고 재최적화·정밀도 점검을 한다. 약한 작은 음수도 임계값만으로 자동 통과시키지 않는다. 수소결합 이합체의 유리한 에너지는 결정 패킹·순수 성분 격자에너지·용해도·흡수율을 입증하지 않는다.
