# 독립 검증 자료와 모델 적용 범위 점검

2026-09-29. 자료 확보·검증 결과이며, 추가 약물 패널의 선정이나 독립 계산 완료를 뜻하지 않는다. 계산 점수는 아직 만들지 않았다.

## 약물: 조건을 추적할 수 있는 후보 자료

[Sugden 등, 2022 원논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC9337750/) 및 [공식 보충자료](https://doi.org/10.1021/acs.cgd.2c00433.s001)를 확보했다. 보충 PDF 31쪽 중 표 S1–S4의 해당 페이지(5–6, 12, 17, 23)는 텍스트와 렌더링을 함께 확인했다. 출판사 Figshare가 제공한 파일 MD5와 일치한다. 원본 SHA-256은 `9b6358abe407a5a17517dc2f7d0096d2dfffe7dcee41fabed283aa162d2e6eaa`이다.

파라세타몰·아스피린·카바마제핀과 10개 상대 성분의 30쌍을 자료 풀로 기록했다. 표 S1–S3의 조건별 210칸을 [CSV](../../data/completion/cocrystal-screen-2022.csv)와 [세부 JSON](../../data/completion/cocrystal-screen-2022.json)으로 옮겼다. 물리적 혼합물 121칸, 다성분 고체 관찰 32칸, 미시도 56칸, 판정 불명 1칸이다. 이 숫자는 서로 독립인 실험의 수가 아니다. 카바마제핀–프로필파라벤의 추가 조건 78칸도 별도로 보관했으며 표 S3와 겹치는 시도를 독립 반복으로 세지 않는다.

주요 공통 조건은 슬러리의 1:1 투입·10–30°C·최대 4주, LAG의 1:1 투입·30 Hz·15분이다. 슬러리와 LAG 용매는 n-heptane/diethyl ether로 구분된다. 각 시도의 정확한 온도·기간과 실제 생성물의 화학량론을 공통 방법 설명으로 채우지 않았다. 피리딘의 용매화물과 공결정을 구분하고, 카바마제핀–프로필파라벤은 후속 혼합물 관측만으로 최초의 판정 불명을 지우지 않는다.

13개 분자는 PubChem의 단일 성분 식별자·분자식·InChIKey와 RDKit 구조를 대조했다. cis-aconitic acid의 Z 입체화학과 3-tert-butyl-4-hydroxyanisole의 치환 위치를 유지했다. 이 단계에서는 수소결합 구조나 DFT 초기 좌표를 생성하지 않았다.

## 공개 모델 자료와의 중복

[DeepCocrystal 저자 저장소](https://github.com/molML/deep-cocrystal)의 커밋 `2805197eff579844b6a45f71a67e2638ede7a14e`에서 학습·검증·시험 CSV와 라이선스를 확보했다. 공개 모델은 논문 전체 자료와 다른 비공개 자료 제외 버전으로 안내되어 있다. 라이선스는 ASL의 학술·비상업 범위이며, 이번에는 데이터를 읽었고 모델 설치·추론·재배포는 하지 않았다.

원자 연결과 입체화학을 보존한 canonical SMILES, 중성화·입체정보 제거 표현, 보수적인 토토머 계열을 각각 비교했다. 역순 분자쌍과 증강 SMILES를 중복 사례로 세지 않았다. 파싱 실패는 없었다. [중복 점검 원시 결과](model-overlap-2022.json)에 행 수, 고유 쌍 수, 대응 라벨과 파일 해시를 남겼다.

| 자료 풀의 쌍 | 공개 학습/검증 자료와 겹침 |
|---|---|
| PARA–OXAL | 검증 자료 |
| PARA–PYRD | 검증 자료; 용매화물 구분 필요 |
| PARA–SUCA | 학습 자료 |
| CARB–NICM | 학습 자료 |
| CARB–OXAL | 학습 자료 |
| CARB–SUCA | 학습 자료 |

30쌍 중 6쌍이 겹쳤다. 나머지 24쌍은 이 CSV에서 일치하지 않았다는 뜻이며, 최종 공개 가중치의 전체 학습 이력을 입증한 것은 아니다. 세 API 모두 학습 자료의 다른 쌍에 등장한다. 따라서 신규 API 일반화 시험으로 부를 수 없다. 같은 CSV의 증강 행 수를 논문의 실험 사례 수와 동일시하지 않는다.

겹치는 쌍을 제외하면 PARA의 확인된 양성 사례가 모두 빠진다. 이 풀을 그대로 사용해 API별 균형 있는 예측 평가가 가능하다고 주장하지 않는다. 후속 선정에서 DFT 규칙의 추가 API 검증과 ML 모델의 미학습 쌍 검증을 구분해야 한다. 비교 방법들에 서로 다른 분모를 숨겨서 사용하지 않는다. 조건이 맞지 않으면 추가 원문을 확보하거나 해당 모델의 독립 성능 주장을 보류한다.

## 반도체: 후보 모델의 실제 범위

| 후보 | 이번에 확인한 근거 | 현재 판정 |
|---|---|---|
| Jornada 층내/층간 분리 모델 | [저자 저장소](https://github.com/jornada-group/mlips_split_data), 커밋 `bee66692c0781424a43653504c5f350d913698e1`. 공개 설정의 학습 파일명은 MoS₂/WSe₂이며 층·원자 위치별 type_names를 사용한다. | MoSe₂ 및 S/Se 교환 계면을 검증된 적용 영역으로 간주할 근거가 없다. 단순 원소 이름 치환으로 본 비교에 넣지 않는다. |
| 2024 TMD 합금 MACE | [공식 Zenodo 배포본](https://zenodo.org/records/10912291)의 약 55.9 MB 아카이브를 내려받아 MD5를 검증하고 학습/시험 구조 전체와 설정을 읽었다. 1,470개 108원자 구조는 단층이며 기록된 MACE 0.2.0 설정의 cutoff는 5 Å이다. | 현재 CI/CO 층간 모델 비교에서 제외한다. 배포본의 단층 범위와 층간 검증 부재가 이유다. 시험 파일 전체가 학습 파일의 앞부분과 바이트 단위로 같으므로 이 시험 묶음을 독립 평가 자료로 사용하지 않는다. |
| 2025 분산 포함 TMD NNP | [원논문](https://www.nature.com/articles/s41524-025-01761-9)은 MoS₂/MoSe₂를 포함한 층상계를 다루고 C09/QE를 사용한다. 자료는 요청 제공이라고 명시한다. | 물리 조건은 가깝지만 실행 가능한 공개 가중치를 아직 확보하지 못했다. 논문의 Se 원자가 전자 6개와 현재 의사퍼텐셜의 16개 차이도 대응 검토가 필요하다. |

설정과 메타데이터는 `data/completion/materials-models/`에 보관했다. 실제 모델 비교는 적합성이 확인된 최대 2개로 제한한다. 이 표는 후보 조사 결과이며 “적합한 공개 모델이 전혀 없다”는 확정 판정이 아니다. 외부 연구자에게 연락하지 않았다.

2026-09-29에 2025 NNP의 [출판사 원문](https://www.nature.com/articles/s41524-025-01761-9)을 다시 확인했다. 데이터 제공 방식은 요청 제공이며 원문에 직접 실행할 가중치 저장소 링크는 없었다. 제목·저자/PANNA·DOI를 사용한 공개 저장소 검색에서도 이번 실행에 사용할 배포본을 확인하지 못했다. 이것은 공개 가중치가 어디에도 없다는 증명이 아니다. 현재는 비교용 파일을 확보하지 못한 후보로 남기고, 자료 요청을 대신해 임의 모델이나 다른 함수의 결과를 동일 기준 비교에 넣지 않는다. MoS₂/MoSe₂ 층상계 지원과 S/Se 치환 환경의 학습 여부도 구분해야 한다.

### 2024 MACE 배포 아카이브 추가 점검

개념 DOI 10.5281/zenodo.10912290에서 받은 메타데이터가 가리키는 실제 버전은 **10912291**이다. `quaternary_repo.zip`은 55,899,962바이트, MD5 `201aa56c63ec99d0e966134a59b4793c`, SHA-256 `cf2cd8a42150959a19a67ecde3b6caf9beb5fc0c3963cee29532570f00cf5e1b`이다. 모델 파일도 배포본 안에 존재함을 확인했지만 로드·추론하지 않았다.

학습 파일은 108원자 구조 1,470개와 고립 원자 4개, 시험 파일은 108원자 구조 1,470개다. 모든 고체 구조에서 Mo/W 원자들의 z 범위는 최대 0.3345 Å, 전체 원자의 z 범위는 최대 3.6595 Å다. 생성 코드와 함께 보면 이번 6–8 Å Mo 평면 간격의 두 층을 학습/검증한 자료가 아니다. `binding_energy` 디렉터리는 같은 단층 안의 W–W 또는 Se–Se 치환 원자 관계에 대한 에너지 계산이며, 파일명만으로 층간 결합 검증으로 분류하면 안 된다. 코드의 격자 변수명은 optB88을 가리키지만 정확한 DFT 입력·의사퍼텐셜은 이번 아카이브 조사에서 확정하지 않았다.

시험 파일 17,330,704바이트 전체가 학습 파일의 앞부분과 정확히 같고, 학습 파일 끝에 고립 원자 자료 1,921바이트만 더 있다. 원자 순서를 유지한 좌표/셀 해시와 원시 프레임 해시로도 1,470개 전체 중복을 확인했다. 따라서 **이 배포본의 시험 점수는 독립된 구조에 대한 검증 근거로 사용하지 않는다.** 논문의 다른 시험, 별도 미배포 자료, MACE 방법 전반에 대한 결론은 이 사실만으로 내리지 않는다. 새 독립 단층 합금 자료를 사용하는 후속 연구에서 이 모델을 검토할 가능성은 남긴다.

[배포본 점검 원시 결과](materials-mace-archive-audit.json)에 파일별 SHA-256, 프레임별 조성·좌표 해시, 설정, 한계를 기록했다. 재현 명령은 `.venv/bin/python scripts/audit_completion_materials_archive.py`이다. 아카이브의 소스 코드나 모델 pickle은 실행하지 않았으며, 설정·학습 로그·구조를 데이터로 읽었다.

## 추가 기반 모델 조사

MACE-MP-0b3와 MACE-MATPES-PBE-0의 공식 공개 릴리즈에 각각 약 79.5 MB 가중치가 등록된 것을 확인했다. 소스까지 확인한 결과, MACE 보조 함수로 D3를 켜도 기본 세 원자 항과 분산 거리 절단이 준비된 QE PBE-D3 조건과 다르다. MATPES의 ASL 사용 요건도 아직 확인되지 않았다. [추가 후보 조사](MATERIALS_FOUNDATION_SCREEN.ko.md)에 고정한 출처·배포 조건·일치 검증 순서를 기록했다. 가중치 취득이나 추론은 하지 않았고, 실제 CI/CO 비교에 적합하다는 판정도 아직 없다. 기존 세 후보의 범위 제한과 새 후보의 조건부 가능성을 함께 유지한다.

## 다음 결정에 미치는 영향

약물은 실패 조건을 확보할 수 있는 구체적인 자료 풀이 생겼다. 하지만 학습 중복을 제거한 분모·API별 양성 사례·생성물 종류를 추가로 검토한 뒤 평가 패널을 고정해야 한다. 반도체는 공개 모델의 존재만으로 합금 계면 비교 가능성을 가정할 수 없으며, 우선 DFT의 수치 정밀도와 치환 위치 효과를 확인해야 한다. 두 분야의 주력 선택은 아직 끝나지 않은 파일럿 결과와 계산 비용을 함께 보고 내린다.


## GPU 활용 요청 후 첫 모델 가중치 확보

공식 MIT 표기 MACE-MP-0b3 medium 가중치 79,472,952 bytes를 받았고, 해시를 고정한 뒤 CPU에서 읽어 Mo·S·Se와 6 Å cutoff를 확인했다. 원본은 float64다. [현재 준비 상태](MACE_GPU_PREPARATION.ko.md)에 근거를 기록했다. 기존 다운로드 전 조사 결과는 보존하며, 실제 모델 추론·GPU 속도·층간 정확도·분산 일치 검증은 아직 남아 있다.
