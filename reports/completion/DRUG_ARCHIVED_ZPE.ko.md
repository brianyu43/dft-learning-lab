# 기존 최소점의 영점 진동 에너지 검토

2026-09-29. 기존 최소점 9개의 실제 Hessian에서 영점 진동 에너지(ZPE)를 추출하고 ORCA 출력과 대조했다. [원시 분석 JSON](drug-archived-zpe-r1.json)은 원래 17개 출발점의 이력과 출처 253개 파일의 해시를 연결한다. 원본 계산과 결과 파일은 수정하지 않았으며 새 엔진 실행은 0건이다. **공통 격자의 전체 패널이나 형성 순위를 완료한 결과는 아니다.**

## 계산한 양

조화 진동 모형에서는 가장 낮은 진동 상태에도 에너지가 남는다. 내부 진동수의 파수 \(\tilde\nu_i\)를 cm⁻¹로 쓸 때 이번 보조값은 다음과 같다.

\[
E_{\mathrm{ZPE}}/E_h=\frac{1}{2}\frac{\sum_i\tilde\nu_i}{219474.63136314},\qquad
E_{\mathrm{보조}}=E_{\mathrm{전자}}+E_{\mathrm{ZPE}}.
\]

분모는 CODATA 2022 값을 사용하는 설치된 SciPy의 Hartree–파수 환산값과 일치한다. kcal/mol 표시는 기존 프로젝트의 627.509474 kcal/mol per Hartree를 유지한다. [SciPy 상수 표](https://docs.scipy.org/doc/scipy/reference/constants.html).

ORCA는 진동수 스케일을 적용한 값을 출력과 `.hess`에 저장하므로 같은 인자를 다시 곱하지 않았다. 이번 9개는 모두 스케일 1.0이며 로그와 Hessian의 인자가 일치한다. 병진·회전 모드 6개를 제외한 3N−6개 내부 모드를 모두 포함했다. [ORCA 진동수·스케일 설명](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/frequencies.html).

ORCA의 열화학 출력은 ZPE 외에 온도에 따른 진동·회전·병진 에너지와 엔트로피를 포함한다. 이번에는 **ZPE만 분리**했고 이들 열적 항을 더하지 않았다. 원래 출력의 298.15 K, 1 atm, Quasi-RRHO 설정은 메타데이터로만 남겼다. 고립 분자의 이러한 보조값으로 공결정 형성 자유에너지를 결정하지 않는다. [ORCA 열화학 설명](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/thermochemistry.html).

9개 모두에서 진동수 합과 ORCA에 소수점 8자리로 인쇄된 ZPE의 차이는 **4.01×10⁻⁹ Hartree 이하**였다. 이는 출력·단위·합산의 일치 확인이며 계산 방법의 물리적 정확도나 격자 수렴 오차를 뜻하지 않는다. 양수인 내부 모드를 임의로 빼지 않았고, 100 cm⁻¹는 낮은 진동수의 개수를 보여 주는 설명용 기준이다. 실제 ORCA 열화학 컷오프는 1 cm⁻¹이고 모든 내부 모드가 그보다 높다.

Hessian의 원자 질량도 기록했다. 이번 자료의 H/C/N/O/F 질량은 각각 1.008/12.011/14.007/15.999/18.998 amu다. 원자 대응과 전체 내부 구조가 최종 좌표와 일치하는지도 재검증했다. CAF p36은 보존된 최적화와 그 좌표에서 별도로 끝난 진동 계산의 연결을 그대로 사용한다.

## 검증과 남은 분석

[8개 검사](drug-zpe-tests-r1.log)는 실제 DIF–DIF의 수치 재현, 9개 이력과 원본 보존, 이미 적용된 스케일의 중복 적용 방지, 0·음수·비유한 모드 거부, 잘못된 좌표·모드 번호·스케일·ZPE 출력·열화학 컷오프 및 변경된 이력의 거부를 확인한다. 여러 열화학 블록이 있는 출력은 임의로 한 블록을 선택하지 않고 별도 검토를 요구한다. [검증 기록](drug-zpe-verification-r1.json).

```sh
.venv/bin/python scripts/completion_drug_zpe.py
.venv/bin/python -m unittest discover -s tests -p 'test_completion_drug_zpe.py' -v
```

각 값은 원래 계산 설정에서 얻은 것이다. 동일한 공통 조건의 17개 최소점이 확보되면 같은 추출을 다시 적용하고, 주 분석인 전자 B/X와 ZPE 보조 차이를 분리해 계산해야 한다. 이번 표에서는 B/X나 자세 순위를 계산하지 않았다. ZPE의 격자 민감도도 아직 검증하지 않았다. wB97X-3c 단일점에는 그 방법으로 계산한 진동수가 없으므로 주 방법의 ZPE를 wB97X-3c 고유 진동 보정으로 표시하지 않는다.
