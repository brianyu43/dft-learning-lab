제어기 원본은 [state.json](../../runs/completion-materials-2026-09-29T095731903472_0000/state.json)에 그대로 보존했다. 제어기가 마지막 종료를 수집하기 전에 멈췄으므로 원본 단계 목록은 14건이다. 마지막 종료 보고서를 따로 검증해 [현재 상태](materials-run-state.json)에 15번째 완료 작업을 명시적으로 보충했다. ## 비용과 보존

[중단 시점 비용 기록](user-stop-resource-cost-r1.json)에 따르면 기존 1·2주차를 포함한 원래 예산에 집계한 실행 시간은 약물 6.179시간, 반도체 6.725시간이다. 실패·중단된 시도도 포함하는 벽시계 시간이며, CPU 코어 시간을 합산한 값이나 프로젝트 전체 작업 시간이 아니다. 이번 반도체 배치는 5.172시간이다. 약물의 1·2주차 기준값에는 xTB 탐색과 병렬 검증이 포함되며 이후 ORCA 시도를 더했다. 따라서 약물 합계를 순수 ORCA 시간으로 해석하지 않는다. 설치·다운로드 시간은 제외한다.

완료된 입력·출력·QE XML·실행 메타데이터와 원본 코드 스냅샷을 보존한다. 공개본은 [공개 범위](../../docs/PUBLIC_RELEASE.ko.md)에 따른 선택본이다. 파동함수·설치물·다운로드 모델·의사퍼텐셜·원본 대화는 공개하지 않는다. 원본 로컬 자료는 삭제하지 않았다. 공개 파일의 경로·크기·해시는 루트 `publication-manifest.json`에 있다.

## 나중에 재개한다면

현재는 재개하지 않는다. 사용자가 다시 요청할 때 [전체 미완료 계획](../../docs/COMPLETION_PLAN.ko.md)과 [체크포인트 JSON](user-stop-checkpoint-r1.json)을 먼저 확인한다. 기존 로컬 환경에서 15건의 완료 보고서·입력·출력 해시를 재검증한 뒤, 같은 배치 명령은 완료 작업을 재사용하고 `w3-hetero-g000-bottom`부터 이어갈 수 있도록 설계돼 있다. 이번 중단 정리에서는 다음 입력 생성이나 새 엔진 실행을 하지 않았다.

재개 시 검토할 명령은 `.venv/bin/python scripts/completion_batch.py --materials --execute`다. 이 명령은 이후 여러 작업을 연속 실행하므로 새 예산과 범위를 먼저 정해야 한다. 공개 복제본에는 엔진·의사퍼텐셜이 없고 원본 절대 경로가 남으므로, 별도 환경 설치와 명시적인 경로 이관 없이 바로 실행할 수 있다고 가정하지 않는다. 약물과 GPU 비교는 각각 준비 단계에 머물러 있으며 자동으로 시작하지 않는다.
