# 2주차 중단·재개 기록

2026-09-10 23:19 KST, 사용자의 “내일 하자” 요청으로 계산을 정지했다. 현재 계산 엔진과 후속 실행기는 모두 종료됐다. 자동 재시작은 설정하지 않았다. 2주차 전체 완료 보고서가 아니다.

완료한 작업은 xTB 505개 시도(491개 수렴, 미수렴 14개 보존), 약물 단량체 두 개의 최적화·진동 검증, MoS₂ 단층 SCF 8개다. 단층 수치 오차는 설정한 기준을 통과했다.

디플루니살–카페인 이합체는 **87회 구조 최적화를 거쳐 수렴했다.** 이후 분석적 진동 계산의 적분 단계에서 사용자 요청으로 정지했다. 이 실행의 실제 경과 시간은 156.34분이며, 이는 완료한 Opt+Freq 비용이 아니다. 진동·국소 최소점·결합 에너지는 아직 미확정이다. 최적화 좌표의 원자 연결과 수소 소유 원자는 유지됐고 분리되지 않았다.

[보존한 최적화 구조](../structures/checkpoints/week2/user-pause-20260910/diflunisal--caffeine-optimized.xyz)의 SHA-256은 `820d5ba77bdd0c689b9823a41e230fc2f15832ee020399934498dca7dd1a56ee`다. 원시 출력, 종료 시점 메타데이터와 GBW 파일도 보존했다. **내일 87회의 최적화를 처음부터 반복할 필요는 없다.** 미완성 진동 계산은 저장한 좌표에서 새로 수행한다.

MPI 4.1.1 설치와 실행기 점검은 완료했다. 실제 ORCA 병렬 계산 비교는 아직 실행하지 않았다. 권장 시작값은 12프로세스이며, 8·12·16프로세스 비교로 조정할 예정이다.

재개 순서:

1. 저장한 최적화 좌표와 해시를 확인한다. 현재 병렬 비교 스크립트의 “전체 핵심 계산 완료” 전제는 이 중단 체크포인트를 받도록 명시적으로 조정해야 한다.
2. 작은 물 분자의 MPI Opt/Freq와 동일한 이합체 좌표의 1·8·12·16프로세스 EnGrad 비교를 실행한다.
3. 검증된 MPI 설정으로 이합체의 별도 Freq 계산을 수행한다. 기존 최적화 로그와 새 Hessian을 함께 검증하도록 분리된 최적화/진동 이력을 지원해야 한다. 현재 일반 파서는 같은 로그 안의 Opt+Freq를 전제로 한다.
4. 준비된 MoS₂ 이중층/분리층 SCF 16개를 실행하고 결과 분석·그림·해시 검증을 마친다.

기존 `drug-first-dft-batch.json`이나 `finish_week2.py`를 그대로 재실행하지 않는다. 정지된 최초 시도를 보존하고 별도 재개 입력과 실행 순서를 만든다. 3주차 전체 약물 대조군·이종 이중층 실험은 시작하지 않았다.
